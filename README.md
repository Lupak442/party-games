# 파티 게임즈 🎲

친구들과 링크/초대코드로 함께 노는 실시간 모바일 파티 게임 (Node.js + Socket.IO).

게임 목록: **마니또 · 라이어 게임 · 바보 라이어 · 스피드 퀴즈 · 블랙잭 🃏**

---

## 🃏 블랙잭 게임
- **정통 52장 덱**: 매 판 새 덱으로 리셋/셔플
- **딜러(서버) 카지노 공식 룰**: 딜러는 16점 이하이면 무조건 히트, 17점 이상이면 무조건 스탠드!
- **2가지 모드 지원**:
  1. **🏆 기본 점수제**: 승리(+1점), 블랙잭 승리(+2점), 패배(0점), 버스트/21초과(-1점) (방장이 점수 커스텀 가능)
  2. **💰 점수 배팅 모드**: 본인 점수에서 1~3점 배팅 ➔ 승리 시 배팅액의 2배 획득, 비기면 원금 회수, 지거나 버스트 시 배팅금 상실!

## 📚 내장 단어 데이터 관리 (AI 없이도 100% 동작)
- 단어 데이터 파일: `server/data/builtins.json`
- 현재 기본 주제: **과일, 동물, 음식, 나라, 직업, 스포츠, 국내 드라마, 영화, 가수, 예능**
- **단어 추가/수정 방법**:
  `server/data/builtins.json` 파일을 열고 원하는 주제를 추가하거나 기존 주제에 단어를 쉼표(`,`)로 이어붙이기만 하면 서버에 즉시 반영됩니다!
  ```json
  {
    "과일": ["사과", "배", "포도", "딸기", ...],
    "내 커스텀 주제": ["단어1", "단어2", "단어3", ...]
  }
  ```

## 🤖 AI 모드 (Google Gemini)
- AI를 사용하고 싶다면 Render 환경변수 또는 로컬 `.env`에 `GEMINI_API_KEY`를 등록하세요.
- AI 모드를 켜면 **"롤 챔피언", "포켓몬", "해리포터 마법"** 등 세상의 어떤 주제를 입력해도 AI가 자동으로 유명한 단어들을 실시간 생성해줍니다.

## 🕵️ 라이어 게임의 "오타 인정" 판정 기능
- 지목된 라이어가 마지막 기회로 정답을 맞출 때, **"딸기"**가 정답인데 **"달기"**처럼 오타를 내거나 띄어쓰기가 달라도 바로 탈락하지 않습니다.
- 심판(기본 방장, 방장이 라이어일 땐 시민 대표)의 화면에 원래 제시어와 라이어가 쓴 답이 나란히 비교되어 뜨며, **[⭕ 정답 인정(오타 인정)]** 버튼을 눌러 점수를 줄 수 있습니다.

## 🚀 로컬 실행
```bash
npm install
npm start          # http://localhost:3000
```
PowerShell에서 AI 키 넣고 실행:
```powershell
$env:GEMINI_API_KEY="내_구글_API_키"; npm start
```

## 🌐 Render 무료 배포
1. GitHub 저장소에 push
2. [render.com](https://render.com) > **New → Blueprint** > `Lupak442/party-games` 선택
3. `render.yaml` 설정 자동 감지 → 배포 시작!
4. 생성된 주소(`https://party-games-xxxx.onrender.com`)를 친구들에게 카톡으로 공유하면 끝!
   *(무료 플랜 절전 방지는 [UptimeRobot](https://uptimerobot.com)으로 `/healthz` URL을 5분마다 핑 등록)*

## 🔄 튕김 방지 & 자동 복귀
- 스마트폰 브라우저 새로고침, 전화 받기, 카톡 확인 등 백그라운드 전환 후 돌아와도 **내 자리(점수, 카드, 투표 상태) 그대로 자동 복귀**.
- 데이터가 지워져도 방에 있던 **내 이름으로 다시 접속하면 이전 자리를 즉시 되찾음**.
